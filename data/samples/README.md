# Satellite Data & Samples Directory

This directory stores sample remote-sensing imagery and benchmark evaluation queries for the SatQuery AI system.

### Suggested Categories
- `airports/`: Runways, aprons, commercial and military aircraft.
- `ports_maritime/`: Berths, cargo ships, tankers, harbor infrastructure.
- `urban_industrial/`: Buildings, warehouses, storage tanks, road intersections.
- `hydrology_environmental/`: Water bodies, floodplains, agricultural fields, deforestation parcels.
- `challenging_cases/`: Cloud occlusion, low-light imagery, extreme off-nadir angles (used to test abstention / refusal logic).
